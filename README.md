# 💬 Real-Time Cloud Chat Application

A modern, responsive real-time chat application built with **Next.js**, **Firebase Authentication**, and **Cloud Firestore**.

## 🚀 Features

* **Secure Authentication:** Instant Google Sign-In powered by Firebase Auth.
* **Real-Time Messaging:** Messages sync and update instantly across all connected clients using Cloud Firestore.
* **Modern UI:** Styled cleanly with Tailwind CSS for an optimal desktop and mobile experience.
* **Secure Environment:** Environment variables protected locally and safely configured for production deployment.

---

## 🛠️ Tech Stack

* **Frontend & Framework:** Next.js (React / TypeScript)
* **Styling:** Tailwind CSS
* **Backend & Database:** Firebase Firestore & Firebase Authentication
